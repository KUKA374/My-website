📚 Сабақ материалдарын басқару

Материал сақталды. Сабақ бетін қайта ашқанда жаңа нұсқа көрсетіледі.
Ескерту: HTML форматындағы қарапайым тегтерді (мысалы, <p>, <strong>, <ul>) қолдануға болады. Бұл кезеңде мәлімет осы браузерде сақталады; кейін ортақ Database + File Storage қосамыз.
