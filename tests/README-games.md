# Ойындарды тексеру

Репозиторий қалтасында тәуелділіксіз тексерулер:

```sh
node tests/games-regression.test.cjs
node tests/grade6-first-three.test.js
```

Браузерлік тексеру үшін Node.js, Playwright және Chromium керек. Осы бұлттық
ортада Playwright дайын, Chromium жолы — `/usr/bin/chromium`.

```sh
node tests/games-browser.test.cjs
```

Басқа ортада Playwright-ты репозиторийден тыс орнатуға болады:

```sh
npm install --prefix /tmp/math-ai-browser --no-package-lock playwright
NODE_PATH=/tmp/math-ai-browser/node_modules CHROMIUM_PATH=/path/to/chromium node tests/games-browser.test.cjs
```

Тест өзі уақытша HTTP-сервер мен браузерді іске қосып, соңында жабады.
`CHROMIUM_PATH` басқа Chromium жолын таңдауға мүмкіндік береді.
`GAMES_SCREENSHOT_DIR=/tmp/math-ai-screens` болса, скриншоттар сол қалтаға жазылады.

Тексерілетін жағдайлар:

- 20 ойынның 5, 6, 7-сынып тапсырмаларымен толық аяқталуы: компьютерде
  1440×1000, телефонда 390×844 — барлығы 120 толық ойын барысы.
- 6-сыныпта әр ойынның нәтижесі, қайта басталуы, мәзірге оралуы және
  көлденең сыйымдылығы; телефон үшін touch/mobile эмуляциясы қолданылады.
- 320×740 экранында барлық ойынның басқару элементтерінің сыйымдылығы.
- Аукцион ставкалары мен банкроттық, қамал қорғанысының таусылуы,
  қайталап жіберу/басудан қорғаныс, Enter пернесі, таймердің бітуі,
  дөңгелек айналғанда ойыннан шығу, тапсырмасы жоқ тоқсан.
- Ойын барысында тапсырмалар базасының өзгермеуі және JavaScript қателерінің болмауы.

Браузердегі тест қана `auth.js` сұрауын рұқсат етілген сессияның шағын
алмастырғышымен ауыстырады. Өндірістік авторизация өзгермейді. Бұл тесттер
Firebase-қа нақты кіруді, нақты телефон құрылғысын немесе басқа браузер
қозғалтқыштарын тексермейді. Скриншоттар көзбен тексеруге арналған;
пиксельдік эталонмен автоматты салыстыру жасалмайды.

## 2-кезеңнің ортақ жүйелері

```sh
node tests/games-runtime.test.cjs
node tests/games-learning.test.cjs
node tests/games-shared-browser.test.cjs
```

Қосымша жиын 20 ойынның жергілікті сақтау/жалғастыруын, үзілісті, көмек
пен оқу нәтижесін, қате есептерді қайта орындауды, сақтау қатесін және
320/768/1440px көріністерді тексереді. Сағат тесттерінде Playwright clock
бет жүктелмей тұрып орнатылады. Архитектура мен шектеулер:
[2-кезең сипаттамасы](../docs/games-stage-2.md).

## 3-кезең: детектив, карточкалар, құпия сан

```sh
node tests/games-mechanics-models.test.cjs
node tests/games-mechanics-browser.test.cjs
```

Модель тесттері дәлелдердің нұсқаларды азайтуын, қорытындының негізділігін,
барлық 990 екі/үш таңбалы сан үшін шарттардың бірмәнділігін және карточканың
бір рет бағалануын тексереді. Браузерлік жиын үш ойынды 390/768/1440px
өлшемдерде 5–7-сыныптармен және барлық 12 қолжетімді тақырыппен толық аяқтайды.
Сондай-ақ болжамдар тарихын, карточкалардың бөлек қайталау қорын,
өзіндік бағаны, үзіліс/шығуды, сақтау/жалғастыруды және ескі сақтау форматының
хабарламасын тексереді. Ортақ көмекші құралдар `tests/helpers/` ішінде.
Бұрынғы екі браузерлік жиын да регрессия үшін орындалуы керек.

Іске асыру, файлдар мен шектеулер: [3-кезең есебі](../docs/games-stage-3.md).

## 3-кезең: сәйкестендіру, қадамдық қате және код

```sh
node tests/games-logic-models.test.cjs
node tests/games-logic-browser.test.cjs
```

Алты модельдік тест эквивалент жауаптардың екіұштылығын, екі бағанның
тәуелсіз араласуын, барлық тақырыптың қадамдық талдауларын, екі бөлімнің
бөлек бағасын, барлық код бөлігінің міндеттілігін және бастапқы нөлдерді
тексереді. 42 браузерлік тест жаңа үш ойынды барлық 12 тақырыппен және
390/768/1440px өлшемдерде толық аяқтайды; ұғым және қолжетімді сызба
режимдерін, үзіліс/сақтау, қате түзету, қос басу, кодты қолмен енгізу және
ескі сессия форматын қамтиды. Нақты толық мәтінмен таңдау қолданылады:
мысалы, `30` және `300` жауаптары тестте шатастырылмайды.

Бұрынғы барлық модульдік және үш браузерлік жиын регрессия үшін сақталған.
Толық есеп: [логикалық ойындар](../docs/games-stage-3-logic.md).

## 3-кезең: арқан, эстафета және көлік

```sh
node tests/games-racing-models.test.cjs
node tests/games-racing-browser.test.cjs
```

8 модельдік тест тең күрделіліктегі есептерді тәуелсіз есептеумен,
жұп жүрістерді, мәре шартын, қосымша раундты, қайталанған әрекетті және
жауапқа тәуелсіз тұрақты қарсылас қозғалысын тексереді. 45 браузерлік тест
390/768/1440px өлшемдерде 5–7-сыныптармен толық ойындарды, барлық 12 тақырыпты,
қатысушы ауысуын, сақтау/үзілісті, мерзімді және қарсылассыз қайталауды қамтиды.
Қарсыластың уақытын тексергенде виртуалды сағат басқарылады; сәндік көріністі
скриншотқа түсірерде анимациялық кадр өткізіледі.

Толық регрессияға бұрынғы барлық модульдік және төрт браузерлік жиын да кіреді.
Ресурс шектеулі ортада ірі браузерлік жиындарды жеке орындаған дұрыс;
тесттің шарттары мен мерзімдерін әлсіретудің қажеті жоқ.
Толық есеп: [жарыс ойындары](../docs/games-stage-3-racing.md).

## 3-кезең: жылдам жауап, блиц, дөңгелек және аукцион

```sh
node tests/games-timed-models.test.cjs
node tests/games-timed-browser.test.cjs
```

6 модельдік тест жалпы/жеке мерзімді, дәл мерзімдегі жауапты, серия бонусын,
барлық сектордың нақты бұрышын, бекітілген ставканы, екі капиталды және бөлек
қалпына келтіру есебін тексереді. Қосымша есептердің жауабы барлық 12 тақырыпта
тәуелсіз есептеледі; жауаптарда екіұштылық пен тапсырма қайталануы тексеріледі.
57 браузерлік тест 390/768/1440px өлшемдер мен 5–7-сыныптарды, пернетақтаны,
уақыт шекарасын, қайталанған әрекеттерді, үзіліс/сақтауды, дөңгелектің нақты
геометриясын және аукцион журналын қамтиды. Жарыс/уақытсыз жаттығу бөлек тексеріледі.

Толық регрессияда бұрынғы бес браузерлік жиын да жеке орындалады. Үлкен
жиындарды қатар іске қоспау браузер ресурстары үшін пайдалы; тест мерзімін
немесе шартын әлсіретпеңіз. Виртуалды сағат нақты ойын таймерін басқарады,
ал скриншот үшін анимациялық кадр өткізіледі. Нақты құрылғы тексеруімен
шатастырмаңыз.

Іске асыру мен шектеулер: [уақыт пен ұпай ойындары](../docs/games-stage-3-timed-score.md).

## 3-кезеңді аяқтау: соңғы жеті ойын

```sh
node tests/games-final-models.test.cjs
node tests/games-final-browser.test.cjs
```

Модельдік жиын барлық 12 тақырыптың үш күрделілік сатысын тәуелсіз
математикалық есептеумен тексереді. Квесттің бекет шарттары, пазлдағы бір
жауапқа бір бөлік, зымыран мен көпірдің аяқталу шарттары, қамалдың қорғанысы
мен жөндеу бағасы, нысананың ұпайы және патшаның әр деңгейдегі 80% шегі қамтылған.

Браузерлік жиын жеті ойынды 5–7-сыныптармен және 390/768/1440px өлшемдерде
басынан соңына дейін орындайды. Әр ойын барлық 12 тақырыппен бөлек аяқталады.
Үзіліс, сақтаудан жалғастыру, қайта бастау, ескі өңдеушілер, қате жауап,
бөлек жаттығу және бұрынғы сессияның түсіндірмесі де тексеріледі.
Нысананың координаталары бастапқы сәндік кадр аяқталған соң өлшенеді;
0/10/100 секунд мәтіні ауысқанда экрандағы да, беттегі де орны өзгермеуі керек.

Толық регрессияға бұрынғы алты браузерлік жиын мен барлық модульдік/деректер
жиындары кіреді. Ірі браузерлік жиындарды ресурсты ескеріп ретімен орындаңыз.
Толық есеп: [соңғы жеті ойын](../docs/games-stage-3-final.md).

## 4-кезең: дизайн, көрсетілім және қолжетімділік

```sh
node tests/games-design-browser.test.cjs
DESIGN_SCREENSHOT_DIR=/tmp/math-ai-design node tests/games-design-browser.test.cjs
```

Жаңа жиын 20 ойынды 320/390/768/1440 px өлшемдерінде басынан қорытындыға
дейін орындайды. Батырмалар кемінде 44×44 px болуы, көлденең сыйымдылық,
проектор, нақты Fullscreen API және оның қате жағдайы, іздеу, пернетақта,
фокус, контраст, қозғалысты азайту және жергілікті көрсету баптаулары тексеріледі.
`DESIGN_CAPTURE_ONLY=1` тек бастапқы көріністерді шолу үшін қолданылады;
толық регрессияда бұл айнымалы берілмеуі керек.

Бұрынғы 409 модульдік/деректер және браузерлік тексеру де өзгеріссіз қайта
орындалады. Авторизация тек тестте алмастырылады. Суреттерді көзбен салыстыру
нақты құрылғы немесе экран оқырманы арқылы тексеруді алмастырмайды.
Толық есеп: [4-кезең дизайны](../docs/games-stage-4-design.md).

## 5-кезең: жариялау алдындағы QA

Барлық бұрынғы 501 тексеру және жаңа қауіпсіздік/пернетақта тесттері:

```sh
python tests/run-games-qa.py
```

Жиындар ресурсты үнемдеу үшін кезекпен орындалады. Node.js, Playwright,
Chromium және Python 3 қажет. Журналдар `/tmp/math-ai-game-qa` ішінде;
`GAME_QA_LOG_DIR` арқылы басқа артефакт қалтасын көрсетуге болады.
`DESIGN_SCREENSHOT_DIR` дизайн скриншоттарын сақтайды. Capture-only баптауы
толық QA іске қосқанда алынып тасталады. Бір жиынды бөлек орындауға болады:

```sh
python tests/run-games-qa.py games-qa-browser.test.cjs
node tests/games-progress.test.cjs
node tests/auth-qa.test.cjs
```

Жаңа тесттер: жергілікті прогрестің сан/массив/модель түрлерін тексеру,
прототип кілттері, сақтау арқылы HTML енгізу, код ұяшығының қолжетімді атауы,
уақыт мәтінінің артық DOM жазуы, 20 ойынды Enter/Space арқылы басқару және
код тапсырмасы/құлып енгізу өрісінен Enter жіберу. Басқару батырмалары native
пернелермен іске қосылады; тест тапсырмалардың дұрыс жауабын күйден оқиды,
бұл математикалық мазмұнның тәуелсіз oracle тексеруін алмастырмайды.

`auth-qa.test.cjs` нақты `auth.js` кодын VM ішінде орындайды, тек Firebase
шекарасын алмастырады. Өндірістік аккаунттар/сервер ережелері тексерілмейді.
Браузер жиындары Chromium-ға арналған. Firefox/WebKit ресми орнатылымы осы
ортада желі саясатымен бұғатталды, оларда нәтиже бар деп есептелмейді.
Толық нәтижелер: [QA есебі](../docs/games-stage-5-qa.md).
