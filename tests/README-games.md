# Ойындарды тексеру

Репозиторий қалтасында тәуелділіксіз тексерулер:

```sh
node tests/games-regression.test.cjs
node tests/grade6-first-three.test.js
```

Браузерлік тексеру үшін Node.js, Playwright және Chromium керек. Осы бұлттық
ортада Playwright дайын, Chromium жолы — `/usr/bin/chromium`.

```sh
node tests/games-browser.test.cjs
```

Басқа ортада Playwright-ты репозиторийден тыс орнатуға болады:

```sh
npm install --prefix /tmp/math-ai-browser --no-package-lock playwright
NODE_PATH=/tmp/math-ai-browser/node_modules CHROMIUM_PATH=/path/to/chromium node tests/games-browser.test.cjs
```

Тест өзі уақытша HTTP-сервер мен браузерді іске қосып, соңында жабады.
`CHROMIUM_PATH` басқа Chromium жолын таңдауға мүмкіндік береді.
`GAMES_SCREENSHOT_DIR=/tmp/math-ai-screens` болса, скриншоттар сол қалтаға жазылады.

Тексерілетін жағдайлар:

- 20 ойынның 5, 6, 7-сынып тапсырмаларымен толық аяқталуы: компьютерде
  1440×1000, телефонда 390×844 — барлығы 120 толық ойын барысы.
- 6-сыныпта әр ойынның нәтижесі, қайта басталуы, мәзірге оралуы және
  көлденең сыйымдылығы; телефон үшін touch/mobile эмуляциясы қолданылады.
- 320×740 экранында барлық ойынның басқару элементтерінің сыйымдылығы.
- Аукцион ставкалары мен банкроттық, қамал қорғанысының таусылуы,
  қайталап жіберу/басудан қорғаныс, Enter пернесі, таймердің бітуі,
  дөңгелек айналғанда ойыннан шығу, тапсырмасы жоқ тоқсан.
- Ойын барысында тапсырмалар базасының өзгермеуі және JavaScript қателерінің болмауы.

Браузердегі тест қана `auth.js` сұрауын рұқсат етілген сессияның шағын
алмастырғышымен ауыстырады. Өндірістік авторизация өзгермейді. Бұл тесттер
Firebase-қа нақты кіруді, нақты телефон құрылғысын немесе басқа браузер
қозғалтқыштарын тексермейді. Скриншоттар көзбен тексеруге арналған;
пиксельдік эталонмен автоматты салыстыру жасалмайды.
