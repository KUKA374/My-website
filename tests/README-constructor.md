# Сабақ конструкторын тексеру

Node.js, Python 3, Playwright және `/usr/bin/chromium` қажет.

```sh
python tests/run-constructor-qa.py
python tests/run-games-qa.py
```

Бірінші команда 47 конструктор тексеруін, екіншісі бұрынғы 565 ойын тексеруін
кезекпен орындайды. Журналдар әдепкіде `/tmp/math-ai-constructor-qa` және
`/tmp/math-ai-game-qa` ішінде. `CONSTRUCTOR_QA_LOG_DIR`, `GAME_QA_LOG_DIR`
арқылы басқа қалтаны көрсетуге болады. Бір файлды жеке орындау:

```sh
python tests/run-constructor-qa.py constructor-library-browser.test.cjs
node tests/constructor-model.test.cjs
```

Браузерлік көмекші тек auth.js желілік шекарасын бақыланатын Firebase SDK-мен
алмастырады. Конструктордың өз рөл/UID тексеруі, каталог, модель, сақтау,
редактор, KaTeX және басып шығару коды нақты орындалады. Бұл нақты Firebase
аккаунтына кіруді немесе серверге орнатылған Firestore ережелерін тексермейді.
`constructor-auth.test.cjs` кештегі жалған рөлді қолданбауды және кешігіп келген
бұрынғы UID жауабы жаңа кітапхананы аша алмайтынын бөлек тексереді.

Тесттер уақытша HTTP-сервер мен Chromium ашады және соңында жабады. Сайтқа
жариялау немесе production дерек жазу орындалмайды. PDF пен экран суреттері
`/workspace/audit-math-ai/stage6-constructor/artifacts` ішінде сақталады.
Екі нақты қойынды тесті ортақ browser context пайдаланады; autosave жарысын
детерминді ұстау үшін екінші қойындының сағаты бақыланады.

Қолмен тексерілетін шекаралар: нақты аккаунттар, нақты телефон/экрандық оқырман,
Firefox/WebKit, операциялық жүйенің PDF диалогы және математикалық мазмұнның
мұғалімдік сараптамасы. Автоматты тесттер бұлардың орнына ұсынылмайды.
