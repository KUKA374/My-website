# iUSTAZ — №1–10 сабақтарды жергілікті компьютерде көру

Бұл тармақ preview архивін жүктеуге арналған. Ол Stage 8D `297f8ea` негізінде жасалған.
Main, GitHub Pages және Firebase production өзгертілмейді. Бұлтқа deploy жасалмайды.

[**Дайын preview ZIP файлын жүктеу — 1,9 МБ**](https://github.com/KUKA374/My-website/raw/refs/heads/preview-stage8d-download/preview/iustaz-stage8d-preview.zip)

Егер тікелей сілтеме ашылмаса, [GitHub-та ZIP файлын ашыңыз](https://github.com/KUKA374/My-website/blob/preview-stage8d-download/preview/iustaz-stage8d-preview.zip)
және **Download raw file** (төмен бағытталған жебе) немесе **View raw** батырмасын басыңыз.

## Іске қосу

1. `iustaz-stage8d-preview.zip` архивін толық ашыңыз.
2. Терминалда архив ашылған қалтаға өтіңіз. Оның ішінде `start_preview.py`, `README_PREVIEW.txt` және `site/` болады.
3. Python 3.9+ арқылы серверді іске қосыңыз:

   ```sh
   python3 start_preview.py
   ```

   Windows-та Python Launcher орнатылған болса:

   ```powershell
   py start_preview.py
   ```

4. Браузерден **http://127.0.0.1:8000/preview.html** ашыңыз.
5. №1–10 сабақтың бірін таңдаңыз. Теория, тапсырмалар, жауаптарды көрсету, презентация, ойындар және ҚМЖ қолжетімді.
6. Серверді тоқтату үшін терминалда **Ctrl+C** басыңыз.

8000 порт бос болмаса, `python3 start_preview.py --port 8765` орындап,
http://127.0.0.1:8765/preview.html ашыңыз.

Каталог жолы: **Сыныптар → 6-сынып → Математика / І тоқсан → сабақ → «Модульдік сабақ көрінісі (демо)»**.
Архивтегі толық нұсқаулық: `README_PREVIEW.txt`.

## Preview ерекшелігі

- Интернетке сайт жарияланбайды: сервер тек жергілікті `127.0.0.1` адресінде жұмыс істейді.
- Нақты Firebase аккаунты қажет емес. Жергілікті тесттік мұғалім профилі қолданылады.
- Preview сервері production Firebase сұрауларын және серверлік жазуды бұғаттайды.
- Сабақ материалдары мен өндірістік Auth/Firebase файлдары өзгертілмеген; сервер жауаптарды тек жергілікті preview кезінде бейімдейді.
- Жеке үй тапсырмасы мен ойын прогресі тек браузердің localStorage қоймасында сақталады.
- Бұл сервер production-ға арналған емес. Нақты production Auth тексерілді деп есептелмейді.
- №11–39 модульдік сабақтары әзірге дайын емес; видеосабақтар қосылмаған.
- №8–10 ойындары қолданыстағы №7 «Пропорция» банкін пайдаланады.

Бұл — бастапқы дайындалған ZIP файлының дәл көшірмесі. Бүтіндігін `SHA256SUMS` файлымен салыстыруға болады.
