# Сабақ конструкторы: A кезеңі — аудит және архитектура

Негізгі main: `3b5213a8a2d19126e1b854125a7c8e13b5312176`.
Тармақ: `stage-6-lesson-constructor`. Main-нің ағашы бұрынғы
`21efe0696d96f8512e0cc84a420fe9e00c81d573` нұсқасымен бірдей:
20 ойынның барлық жетілдіруі және 565 тест сақталған.

## Қазіргі жағдай

- constructor.html негізгі өрістерді, мәтіндік бөлімдерді, escaped preview,
  басып шығаруды және бір сабақты `mathTeacherCustomLesson` кілтімен сақтауды қолдайды.
- Сабақ тізімі, уақыт кезеңдері, тапсырма банкі, дескриптор ұпайы, автоматты
  сақтау, иелік, көшіру, қауіпсіз жою және жеке оқушы экспорты жоқ.
- curriculum-data.js 5–11-сыныптарды және пән/бағыт/тоқсанды жариялайды.
  КТП файлдары нақты тақырып пен оқу мақсатын береді. 1–4-сынып дерегі жоқ.
  Жоқ мазмұн автоматты түрде дайын материалмен алмастырылмайды.
- lesson-content*.js авторлық материал мен үлгілерді HTML түрінде сақтайды.
  Конструктор оларды инертті DOM арқылы оқып, тек мәтін/құрылымға айналдырады;
  бастапқы HTML редакторға орындалатын код ретінде көшірілмейді.
- games.html жүктейтін нақты ойын кодында URL параметрлерін қабылдайтын
  іске қосқыш жоқ. Сондықтан games.html сілтемесіне ойдан query қосылмайды:
  мұғалімге сол бетте сынып/ойын/тақырыпты таңдау керектігі түсіндіріледі.
  Сабақтағы ойын уақыты ойынның қолдамайтын таймер параметріне айналмайды.
- auth.js рөлді Firebase профилінен тексереді, бастапқы sessionStorage тек кэш.
  Жеке сабақ иелігін осы кэшпен анықтауға болмайды.
- Firestore users құжаттарын клиенттен жазу жабық; lessonMaterials жазуы
  admin/super_admin-ға ғана арналған. Мұғалімнің жеке жоспар коллекциясы жоқ.
  Сондықтан бұл жұмыста серверлік сақтау және қауіпсіздік ережелерін өзгерту жоқ.
- my-lessons.js сақталған КТП сілтемелерін бөлек кілттермен ұстайды.
  Сол коллекциялар да, бұрынғы конструктор кілті де өшірілмейді.

## Модульдер мен қауіпсіздік шекарасы

Жаңа модульдер: модель/уақыт/бағалау, КТП және контент адаптері, мәтін мен
формуланы көрсету, тапсырма редакторы, ойын метадерегі, иелікке бөлінген
жергілікті репозиторий және интерфейс үйлестірушісі. Қолданыстағы ойын,
тапсырма, auth, сабақ және Firestore файлдары өзгертілмейді.

Жаңа сабақ schemaVersion арқылы нұсқаланады. Барлық сақтау JSON түрлері мен
өлшем шектері арқылы тексеріледі. UI тек нақты Firebase uid және жарамды
рөл расталғаннан кейін жеке кітапхананы ашады. localStorage серверлік
қорғаныс емес: ортақ құрылғыдағы жергілікті файлға тікелей қол жеткізетін
адамнан құпиялылықты қамтамасыз етпейді. Интерфейс бұл шектеуді түсіндіреді.

LaTeX жергілікті KaTeX арқылы trust=false режимінде көрсетіледі. Қарапайым
мәтін әрдайым escape жасалады; еркін HTML/JS, қауіпті URL не SVG орындалмайды.
Материалды дайын деп белгілеу үшін мұғалімнің мазмұнды тексеруі қажет;
авторлық үлгі немесе генерация тексерілген оқу материалы деп аталмайды.
