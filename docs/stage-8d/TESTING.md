## Математика және оқу мақсаты

`tests/check-stage8d-math.py` сайттағы калькулятор мен жауап тексерушісін импорттамайды.
Python AST және Fraction арқылы рационал сандар, қысқартылған кері қатынастар, пропорция
анықтамасы, масштабтау, төрт позициядағы белгісіз, аффиндік мүшелер, сызықтық теңдеулер
және тура пропорционалдықтың тұрақты коэффициенті тәуелсіз есептеледі. Нөл бөлімдер,
сызықтық емес өрнектер, жалған теңдіктер және орындалатын код синтаксисі қабылданбайды.

Барлық **95 жауап** (75 тапсырма + 20 мысал) есептелген мәнмен дәл салыстырылды.
**394 теңдік** тексерілді: 227 сандық шешім, 65 символдық қойып тексеру,
10 теория, 72 слайдтағы қадам және 20 сандық TeX формуласы.
Бұл ішкі assertions; олар 394 жеке тест ретінде жалпы санға қосылмайды.
48 жаңа слайдтың әрқайсысы нақты Chromium-да KaTeX strict режимімен көрсетілді.

Теориядағы анықтамалар, есеп шарттары мен амалдардың сәйкестігі, өлшем бірліктері,
теріс мысалдар және оқу мақсатына сәйкестік авторлық математикалық шолудан өтті.
Бұл сыртқы сарапшының сертификаты емес; `reviewRequired: true` сақталған.
№6 — кері қатынас; №7 — анықтама/құрастыру; №8 — негізгі қасиет; №9 — оны қолдану;
№10 — тек тура пропорционалдық. №8 және №9 ортақ ресми мақсатты қайталанбайтын
жаңа контекстермен бекітеді. №1–10 бойынша 150 тапсырма мәтінінің бірегейлігі тексерілді.

## Браузер, сақтау, ҚМЖ

Chromium, 320, 390, 768 және 1440 px: **бес сабақ × төрт экран = 20 толық ағым**.
Әр ағымда КТП атауы/бөлімі/мақсаты, бірінші болып видеосабақтың бос күйі, 4 мысал,
3 кезекті жұптық, 4 топтық, A/B/C деңгейлерінің әрқайсысындағы 2 есеп, жасырылған
жауаптар мен мұғалім басқаруы, 20 ойын каталогы, ҚМЖ және слайд диапазоны тексерілді.

Ашылған сабақ тек өз JSON-ы мен тоқсан индексін сұрайды; слайдтар ашылғанша жүктелмейді.
Материал JSON-дарының көлемдері: №6 — 24 460; №7 — 24 675; №8 — 22 687;
№9 — 24 117; №10 — 26 387 байт. Loader-дің 128 KiB құжат шегінен төмен.
Бұрынғы кэш/жад шегі мен қате/жою/қайта жүктеу сценарийлерінің тесттері де өтті.

Әр жаңа сабақтың жеке үй тапсырмасы қайта жүктегеннен кейін сақталды; сабақтар арасында
араласпады. Бұрынғы UID оқшаулауы, екі қойындыдағы revision қақтығысы және конструктор
кітапханасын сақтау тесттері өтті. Нақты production Firebase қолданушылары пайдаланылмады:
браузерлік Auth шекарасы тесттік мұғалім профилімен алмастырылды.

ҚМЖ HTML, JS және стилі өзгермеген. Бес жаңа ҚМЖ-ның 45 минуттық кезеңдері, нақты КТП
метадеректері және print көрінісінде жауаптардың жасырылуы телефон/desktop өлшемінде
тексеріліп, бес A4 PDF жасалды. PDF — браузердің басып шығару әрекеті, серверлік экспорт емес.
Телефон/desktop көрнекіліктері мен слайд скриншоттары көзбен қаралды; көлденең overflow жоқ.

## Түзетілген сәйкессіздіктер

- Бұрын бет ойын тақырыбын тек КТП нөмірінен іздегендіктен, банкте №8–10 болмаған кезде
  ойын таңдауы жабылатын. Сабақтың нақты бар `games.topicKey` көзін қабылдайтын шағын
  адаптер қосылды; өзге сынып/пән/тоқсан не жоқ тақырып қабылданбайды. Дереккөз ашық жазылады.
- Бұрынғы readiness тесттері №6-ны дайын емес деп күткен. Енді №1–10 дайын, №11–39 бос;
  shared presentation тесті №8/9 ортақ блогына көшірілді.
- Браузерлік тесттерде жоқ DOM селекторы, каталогтың жаңа қойындысын күту және бос
  презентацияның disabled орнына hidden күйін тексеру сәйкестендірілді. Өнімнің дұрыс
  жұмыс істеп тұрған әрекеттері осы үшін өзгертілген жоқ. Соңғы 23 және 24 тест толық өтті.

- Қайта жалғастыру кезінде уақытша `axe-core` тәуелділігі болмады; ресми npm-нен
  дәл 4.10.3 нұсқасы `--ignore-scripts` арқылы қалпына келтірілді. Өнім коды өзгертілмеді.
- Конструктордың пернетақта тесті `setTimeout(..., 0)` арқылы ауысатын фокусты ерте
  тексеретін. Тек тестке `stagesSection` нақты белсенді болғанша күту қосылды.
  Конструктордың JS/HTML/CSS кодына өзгеріс енгізілген жоқ; 47 тест қайта өтті.

111 бастапқы қорғалған файлдың hash-келісімі, Stage 8C-нің бес JSON-ы мен ескі презентациялар,
КТП-ның 64 контексті және 1 526 бастапқы жолы сақталғаны тексерілді. ҚМЖ мен controller-де
ойын интеграциясынан басқа өзгеріс жоқ. Құпия кілт үлгілерін іздеу жаңа материалдарда нәтиже таппады.

## Қайта орындау

Қолжетімділік тексеруіне ресми `axe-core@4.10.3` қажет. Қалпына келтірілген құрал
репозиторийге қосылмай, уақытша қалтада сақталды. Осы ортада орындалған команда:

```sh
IUSTAZ_AXE_PATH=/tmp/iustaz-stage8d-resume/tools/package/axe.min.js python tests/run-lesson-material-qa.py
python -B tests/check-stage8d-math.py
python tests/run-constructor-qa.py
node tests/iustaz-catalog-browser.test.cjs
node tests/iustaz-contract.test.cjs
python tests/run-games-qa.py games-runtime.test.cjs games-learning.test.cjs games-regression.test.cjs grade6-first-three.test.js games-mechanics-models.test.cjs games-logic-models.test.cjs games-racing-models.test.cjs games-timed-models.test.cjs games-final-models.test.cjs games-progress.test.cjs auth-qa.test.cjs games-browser.test.cjs
```

## Шектеулер және жариялау

Firefox/WebKit, физикалық телефон, нақты принтер, production Auth/Firestore және видео
тексерілген жоқ. Барлық 565 тарихи ойын тесті қайта орындалды деп айтылмайды: таңдалған
116 тест барлық 20 ойынды desktop/mobile және 5/6/7 контекстінде қамтиды.
7 Firestore Emulator тесті осы контент кезеңінде қайта орындалмады: rules өзгерген жоқ;
қолданыстағы 2 қауіпсіздік келісімі өтті. Production Firebase deploy жасалмайды.

Stage 8C әлі main ішінде болмағандықтан, ұсынылған Stage 8D Draft PR соған тәуелді.
Қолданыстағы security workflow тек main-ға PR кезінде іске қосылады; stacked PR үшін
автоматты CI нәтижесі бар деп көрсетілмейді. Main-ға ауысқаннан кейін CI-ді қайта орындау керек.
Жариялау туралы шешім мұғалім шолуы мен PR тексеруінен кейін бөлек қабылданады.
