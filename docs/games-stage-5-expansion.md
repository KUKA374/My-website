# Math AI: 1–11-сыныптарға кеңейтуге дайындық

Бұл — 5-кезеңдегі архитектуралық бағалау және көшу жоспары. Жаңа сыныптардың
тапсырмалары қосылған жоқ. Қолданыстағы 5–7-сынып базасы өзгертілген жоқ.
Негіз: `eb83a440fa1c3be87906cabad57beac46aebc041`.

## Қазіргі дайындық: жартылай

Сағат, үзіліс, нәтиже, көмек, командалардың кезегі және көрініс қабаттарын
қайта пайдалануға болады. Бірақ қазіргі жобаға жаңа сыныптың JSON файлын
қосу ғана барлық 20 ойында сол сыныпты дұрыс қолдауға жеткіліксіз.
Мазмұнды таңдау, құрастыру және кейбір тексеру ережелері ойын файлдарында
тақырыптарға тәуелді. «Ойын кодын өзгертпей 1–11-сынып қосуға дайын» деп
жариялауға негіз жоқ.

| Қабат | Нақты жағдай | Кеңейтуге кедергі |
| --- | --- | --- |
| `curriculum-data.js` | 5–11-сынып навигациясы; 5–6 математика, кейін алгебра/геометрия, 10–11 бағыттары | 1–4-сынып жоқ; навигация ойын мазмұнының бар екенін білдірмейді |
| `games.js`, `populateLessonSelect` | Ойындарда 5, 6, 7 және `math`/`algebra` нақты тізілген | Жаңа сынып/пән үшін UI кодын өзгерту керек |
| `games-data.js`, `games-extra-v5.js` | 12 тақырып: `5-math-1-1`, `6-math-1-1`…`6-math-1-7`, `7-algebra-1-1`…`7-algebra-1-4` | 1–11 толық оқу бағдарламасы емес; бос тоқсандар қолжетімсіз |
| `getGameQuestions` | Бірнеше адаптер бұрынғы провайдерді орап, өз мазмұнын береді | Бір орталық каталог пен бірыңғай мүмкіндіктер шарты жоқ |
| `games-logic-content.js` | Ұғым, сызба, алғашқы қате, түзету материалдары | Әр жаңа тақырыпқа арнайы авторлық ресурс керек |
| `games-racing-content.js`, `games-timed-content.js`, `games-final-content.js` | Қазіргі тақырыптар бойынша кодпен есеп құрастыру; соңғы қабатта 0–2 деңгей | Банкке жазба қосу бұл генераторларға жаңа тақырып қоспайды |
| Детектив/Құпия сан | Есептермен бірге оқиға, дәлел және бірмәнді шарттар құрастырылады | Кез келген тапсырманы осы механикаға тікелей салуға болмайды |
| Жауапты тексеру | Сан, ондық үтір, бөлшек, қатынас және мәтіндік түрлер бар | Жалпы символдық алгебра, бірнеше түбір, өлшем бірлігі, дәлелдеу үшін жеке тексергіштер керек |
| Прогресс v1 | Тапсырмалар model/engine ішінде қайталанады, банк JSON-ы салыстырылады | Каталог нұсқасы/тұрақты ID жоқ; сынып кілті 5–7-ге байланған |

Ескі құрылымдар да әртүрлі: жұптастыруда `left/right`, қате есепте
`statement/error/correction`, қарапайым есепте `question/answer/options`,
кодта қосымша `code`. Қазіргі модерн адаптерлердің қосымша `steps`,
`_finalMeta`, `facts`, `_sessionKey` өрістері бар. Бұларды бірдей викторина
форматына қысқарту жеке механикаларды жоғалтады.

## Ұсынылатын құрылым

1. **Оқу бағдарламасының манифесті.** Сынып, пән, бағыт, тоқсан, тақырып,
   оқу мақсаты және қазақша атау дерек түрінде беріледі. UI қолжетімді
   сыныптарды манифест пен жарияланған тапсырмалардан оқиды. Бос тақырып
   себебімен бірге өшіріледі; басқа тақырыптың есебімен жасырын алмастырылмайды.
2. **Нұсқаланған TaskCatalog.** Әр тапсырманың өзгермейтін `id`, `revision`,
   `grade`, `subjectId`, `topicId`, `objectiveIds`, `difficulty`, `locale`,
   `prompt`, `answer`, `hint`, `workedSolution`, `estimatedSeconds` өрістері
   болады. Мәтін/математика/сызба — түрі анық деректер; еркін орындалатын JS емес.
   Банк нұсқасы мен редакторлық тексеру мәртебесі бөлек сақталады.
3. **Түрлері анық жауап тексергіштері.** `integer`, `rational`, `decimal`,
   `choice`, `set`, `expression` сияқты тексергіш реестрі. Дәлдік, өлшем бірлігі,
   ретке тәуелділік, рұқсат етілген жазылым алдын ала көрсетіледі. Жаңа
   тексергіш тестпен қосылады; контенттен `eval` не функция орындалмайды.
   Қазіргі мәтіндік теңестіру толық компьютерлік алгебра ретінде ұсынылмайды.
4. **ContentProvider шарты.** `listTopics()`, `eligibleTasks(request)`,
   `materialize(taskId, seed)`, `explain(taskId)`; жауапта нақты пән/тақырып,
   нұсқа, дағды және сәйкестік себептері қайтарылады. Алдымен қазіргі банктерді
   өзгертпей оқитын LegacyProvider жасалады. Тақырыптық генераторлар кейін осы
   интерфейстің артына көшіріледі; қозғалыс/ұпай/кезек кодтары сақталады.
5. **GameCapabilities және сәйкестік шешушісі.** Ойын қажетті тапсырма түрлерін,
   санын, уақытын және қосымша ресурстарын жариялайды. Шешуші жарамды ID тізімін
   немесе «сызба жоқ», «жұп екіұшты», «қысқа есеп жетіспейді» сияқты қазақша
   себеп береді. Тақырып атауының ұқсастығы жарамдылық дәлелі болмайды.
6. **Сессия v2.** Банк көшірмесінің орнына каталог нұсқасы, тапсырма ID/нұсқасы,
   генератор seed-і, реті, жауаптар және ойын күйі сақталады. Жергілікті прогресс
   серверлік бағамен шатастырылмайды. Каталогтағы бұрынғы нұсқа жоғалса, түсінікті
   қалпына келтіру/жаңа ойын ұсынылады; жауаптар үнсіз басқа есепке көшірілмейді.

Мысал сұрау шарты: `{grade:6, subjectId:"math", topicId:"fractions",
 difficulty:"basic", gameId:"quick-answer", locale:"kk"}`. Бұл тек ұсыныс;
осы кезеңде манифест, жаңа API немесе жаңа тапсырмалар енгізілген жоқ.
Жаңа мазмұн қолдау көрсетілген тексергіш пен ресурс түрлерін пайдаланса,
ойын кодын өзгертпей қосылады. Мүлдем жаңа өзара әрекет не жауап түрі үшін
жаңа тексергіш/рендерер қосу бәрібір қажет болады.

| Қатені тап | Нөмірлі шешім; дәл бір алғашқы қате; дұрыс түзету; толық дұрыс шешім |

| Математикалық код | Әр есепке бөлік алу ережесі; тұрақты мәтіндік код; бастапқы нөлдер; толықтық шарты |
| Детектив | Оқиға, ықтимал қорытындылар, дәлелдер; барлық дәлелден бір ғана қолдау тапқан қорытынды |
| Арқан тартыс | Командаларға бірдей дағды/қиындық/шешу уақыты бар жұпталған есептер; қосымша раунд қоры |
| Математикалық жарыс | Әділ жұпталған есептер; таңдау/енгізу/тұжырым бекеттеріне жарамдылық; қосымша раунд |

| Блиц | Әдеткі 12 секундқа лайық, қысқа әрі анық жауап; жаттығудың бөлек уақыт саясаты |

| Квест | Бекеттерге арналған бірнеше тапсырма түрі, оның ішінде жұп және қате талдау; карта ресурстары |
| Құпия сан | Жасырын сан, ашылатын шарттар және барлық шартпен жалғыз сан қалатынының тексеруі |
| Пазл | Қазіргі торға жеткілікті бірегей есептер, бөліктер картасы, сурет және балама мәтін |
| Зымыран | Қазіргі алты кезеңге есептер; қиындықтың өсуі; бірмәнді енгізілетін жауап |
| Қамал | Қазіргі алты толқынға таңдау есептері; әділ қиындық пен жеткілікті қор |
| Көлік жарысы | Бекеттерге лайық есеп; жауабы бірмәнді; қарсылас жылдамдығы есеп жауабына тәуелсіз |
| Нысана | Бір ғана математикалық дұрыс нұсқа; қайталанбайтын жауаптар; ұпай координатадан тәуелсіз |
| Көпір | Қазіргі алты бөлікке бірмәнді есептер; белгіленген уақытқа сәйкестік |
| Математика патшасы | Үш дағды деңгейі және қорытынды сынақ; әр міндетті кезеңге негізгі, ұқсас жаттығу және жаңа қайта сынақ қоры |

Тек белгілеулерге сену жеткіліксіз. Контент валидаторы таңдау жауаптарының
канондық бірегейлігін, бөлшектің нөл емес бөлімін, қате қадамның бірмәнділігін,
дәлел/шарт шешімдерінің санын, формула мен сызбаның сәйкестігін тексеруі тиіс.
Генераторлар үшін бекітілген seed матрицасы және тәуелсіз математикалық oracle
қажет. Оқу мақсаты, жас ерекшелігі, мәтін және уақыт нормасы мұғалімнің
редакторлық тексеруінен өтеді; автоматты теңдік оны алмастырмайды.

## Қауіпсіз кезеңдік көшу

1. Қазіргі 12 тақырып пен 20 ойынның инвентарін және банк хэштерін бекіту.
2. Манифест/schema/валидатор және тек оқитын LegacyProvider енгізу. Ескі және
   жаңа провайдер нәтижелерінің математикалық теңдігін тестпен салыстыру.
3. Сәйкестік есептерін алдымен диагностикалық режимде шығару. Жарамсыз
   тақырыпты бастауға жібермеу; қолданыстағы жарамды ойындарды сақтау.
4. Бір ойынның контент таңдауын ғана провайдерге ауыстырып, барлық 20 ойынның
   регрессиясын жүргізу. Кейін қалған адаптерлерді бөлек көшіру.
5. Сессия v2 миграциясын нақты v1 сақталымдармен тексеру. Нұсқасы үйлеспесе
   деректі үнсіз өшірудің орнына түсіндіру және жаңа ойын жолын беру.
6. Тек осыдан кейін бөлек бекітілген тапсырмамен жаңа сынып мазмұнын қосу.
   Деректерді жариялау рөлі серверде тексеріледі; клиенттегі рөл жеткіліксіз.

Қабылдау шарты: бұрынғы банк хэштері өзгермейді; бұрынғы 501 тест және жаңа
каталог/сәйкестік/миграция тесттері өтеді; әр жарияланған тақырыптың әр ойынға
жарамдылығы дәлелденеді; desktop/mobile/keyboard және қолжетімді сызбалар
тексеріледі. Осы жоспардың болуы іске асырылған кеңейту ретінде есептелмейді.
