# Math AI: қауіпсіз жариялауға дайындық жоспары

Бұл құжат жариялау әрекетін орындамайды. 5-кезеңде GitHub-қа push,
`main`-ге біріктіру, Pull Request ашу немесе GitHub Pages жариялау жасалмады.

## Git негізі және main-мен салыстыру

- Репозиторий: `https://github.com/KUKA374/My-website.git`.
- Жұмыс тармағы: `stage-5-final-qa`.
- Негіз: `eb83a440fa1c3be87906cabad57beac46aebc041`.
- Тексеру кезінде `git fetch origin main --no-tags` арқылы тек қашықтағы күй оқылды.
- Соңғы алынған main: `f181f3fffcd118c494caa63a0854274b0199f02a`.
- `main...негіз` аралығы: main жағында 0, жұмыс негізінде 7 commit.
  `git merge-base --is-ancestor origin/main eb83a440...` нәтижесі 0.
  Тарихтар бөлінбеген; осы алынған main-ге қатысты біріктіру қайшылығы жоқ.
- 5-кезеңге дейінгі жинақталған айырмашылық: 56 файл, 15357 қосылған және
  90 жойылған жол. Оған 2–4-кезеңдердің ойын модульдері, тесттері және есептері
  кіреді. Болашақ PR тек соңғы QA түзетуімен шектелмейді: барлық 7 кезеңдік
  commit және осы QA commit толық қаралуы керек.

Репозиторийде `.github` жариялау workflow-ы немесе басқа орналастыру конфигурациясы
табылмады. GitHub Pages конфигурациясын тек оқу үшін API-дан сұрау `Forbidden`
жауабымен орындалмады. Сондықтан Pages-тің нақты source branch/trigger баптауы
осы ортада расталған жоқ. Branch-based Pages сайтында main-ге біріктірудің өзі
автоматты жариялауды бастауы мүмкін. Баптау тексеріліп, жариялауға бөлек рұқсат
алынбайынша біріктіру қадамы орындалмауы тиіс.

Соңғы тексеру алдында main қайта fetch жасалды, хэш өзгермеген.
QA өзгерісі 12 файлды қамтиды, оның 8-і жаңа. Оны қосқаннан кейін main-мен
жинақталған шолу 64 файлды және 8 кезеңдік commit-ті қамтиды.

Бұл қорытынды тек жоғарыдағы main хэшіне қатысты. Кейінгі қашықтағы өзгерістер
қазіргі тексерумен қамтылмайды. Жариялау алдында fetch пен салыстыру қайталанады.

## Жариялау алдындағы реттілік

1. Жергілікті QA commit-тің хэші, тест журналдары, өзгермеген банк хэштері және
   екі есеп бір шолуға біріктіріледі. `git diff --check` және таза жұмыс қалтасы
   тексеріледі. Каталогтағы жаңа `games-progress.js` файлы жеткізілімге кіреді;
   `games.html` ішіндегі өзгерген JS нұсқа сұраулары кэшпен салыстырылады.
2. Алынған main қайта тексеріледі. Жаңа commit пайда болса, өзгерістер жеке
   тармақта біріктіріліп, толық регрессия қайта орындалады. `main`-ге күшпен push
   қолданылмайды.
3. Толық 501 бұрынғы тексеру және жаңа QA тесттері CI/жеке тексеру ортасында
   қайталанады. Chromium-нан бөлек Firefox/WebKit жұмыс істейтін ортада
   прогресс, сағат шекаралары, толық экран және мобильді көрініс тексеріледі.
   Қазіргі ортада ресми браузер жүктеулерін желі саясаты бұғаттады.
4. Рұқсат берілген тест аккаунттарымен Firebase-қа кіру, teacher/admin/super_admin
   маршруттары, рұқсатсыз оқудың/жазудың бас тартуы және нақты орнатылған Firestore
   ережелері тексеріледі. Репозиторийдегі ережелерді оқу сервердегі нұсқаны
   дәлелдемейді. Ойын тесттеріндегі auth алмастырғыш бұл қадамды алмастырмайды.
5. Бұрынғы жарияланған main хэші мен орналастыру артефактісі қайтару нүктесі
   ретінде жазылады. Бұл өзгерістерге банк/Firestore миграциясы қажет емес;
   қолданушының жергілікті прогресін сервер нәтижесі деп көшіру жасалмайды.
6. Пайдаланушы бөлек рұқсат бергеннен кейін ғана тармақ push жасалып, PR ашылады.
   Ревьюде бүкіл айырмашылық, қауіпсіздік шекарасы, сыртқы HTML контентінің
   сенімділік моделі және қалған тәуекелдер қаралады. Біріктіру мен Pages-ті
   жариялауға да нақты рұқсат керек.
7. Рұқсат етілген жариялаудан кейін нақты URL-де каталог, 20 ойынның ашылуы,
   үш өкіл ойында толық аяқталу, авторизация, ресурс 404/консоль қателері және
   390 px көрініс smoke-тексеруден өтеді. Ақау болса, алдыңғы артефактіге
   қайтарылады; база өзгертілмегендіктен кері дерек миграциясы талап етілмейді.

## Дайындық шекарасы

Жергілікті автоматтандырылған QA өтуі жариялауға толық рұқсат немесе нақты
өндірістік қауіпсіздік кепілдігі емес. Қалған браузерлер, нақты аккаунттар,
орнатылған ережелер және нақты құрылғыдағы қолжетімділік жариялау алдындағы
қабылдаудың бөлек шарттары. Тәуекелдер толық [QA есебінде](games-stage-5-qa.md).
