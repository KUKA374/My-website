# iUSTAZ — Stage 7 қорытынды есебі

Негізгі commit: `aec82ab8031af671b3ffdfeba1d25620c81abda6` — Stage 6 толық біріктірілген main. Тармақ: `stage-7-iustaz-redesign`. Жұмыс бастапқы таза main-нен басталды. main-ге жазу, push, PR, merge немесе жариялау жасалмады.

## Нәтиже және беттер

Math AI / Math Teacher көрінетін бренді **iUSTAZ**, ұраны **«Ұстаздың цифрлық серігі»** болып жаңартылды. Техникалық идентификаторлар, URL келісімдері, Firebase конфигурациясы және сақтау кілттері сақталды.

| Бет | Жаңарту |
|---|---|
| index.html | Нақты деректер dashboard-ы, қонақ режимі, жылдам әрекеттер, соңғы UID-сабақтар, сыныптар және бұрынғы жинақтар |
| class.html | 5–11 сынып, барлық пән/тоқсан карточкалары, КТП мазмұнын адал көрсету |
| lesson.html | Бірізді бөлімдер, қолдағы қауіпсіз мысалдар, жоқ материал белгілері, жаңа конструктор жоспарына КТП сілтемесі |
| constructor.html | Үш панельдің iUSTAZ көрінісі, фокус/айналдыру сақталды, жергілікті кітапхана іздеуі мен сынып сүзгісі |
| games.html | 20 ойын каталогы, жұмыс түрі, іске қосу белгісі, нақты 5–7 банк тақырыптары бойынша баптау |
| qmj.html | Бұрынғы ҚМЖ редакторының ортақ chrome және бейімделген көрінісі |
| admin.html | Ортақ навигация, қазақша рөлдер, нақты редактор шектеуі, іске аспаған батырмалар «Жақында» күйінде |
| login.html | Жаңа бренд пен қауіпсіз қате хабарламасы, бұрынғы credential/loginUser әрекеті сақталған |

Сол жақ навигация desktop-та тұрақты, 1200 px-ден төмен жиналатын мәзір. Мәзірде Escape, focus trap, inert және фокусты қайтару бар. Header бөлім іздеуін, нақты рөлге сай профильді, кіру/шығуды береді. Хабарламалар, AI, аналитика, зертхана және баптаулар дайын функция ретінде көрсетілмейді.

## Бренд және дизайн жүйесі

Түпнұсқа ашық кітап/i белгісі SVG форматында: толық және қысқа ашық/қараңғы нұсқалар, favicon. Негізгі түстер: #6C3BFF, #9675FF, #EDE9FF, #FFFFFF, #171329. Жергілікті Inter variable қарпінің Latin/Cyrillic/Cyrillic Extended файлдары және OFL лицензиясы қосылды; жүйелік sans-serif fallback бар.

`iustaz-ui.css` айнымалылар мен компоненттерді береді: навигация, header, карточка, батырма, өріс, modal/dropdown, tabs, badge, toast, tooltip, бос/жүктелу/қате күйі, progress, search, table, breadcrumb. Бастапқы стильдер өшірілген жоқ. Қозғалысты азайту қолдауы және көрінетін focus бар. Белсенді ойындардың сахнасы өзіндік стилін сақтайды; сайт chrome-ы сол кезде жасырылады.

## Деректер және сақталған функциялар

106 бастапқы JavaScript/CSS/ережелер файлы SHA-256 бойынша өзгермеген: барлық ойын механикасы, конструктор логикасы, 5–7 тапсырмалар, КТП, авторизация, Firebase ережелері және бастапқы CSS. Бұрынғы root JavaScript ішінен тек search.js қауіпсіз мәтін шығару үшін түзетілді.

Сабақтарды сақтау Stage 6 UID бойынша бөлінген жергілікті repository-ге сүйенеді. Жаңа UI тек оқиды; ашу/көшіру/жою/сақтау бұрынғы батырмалар арқылы орындалады. Бұл серверде сақталған не шифрланған қойма емес. Firebase рөлі/UID расталмай жеке жоспарлар ашылмайды. Жаңа серверлік сақтау қосылмаған.

Ойындармен URL байланысы, таймер, үзіліс, көмек, ұпай, сақтау/жалғастыру, қайта бастау сақталды. Каталог сүзгісіндегі 12 тақырып барлық 20 ойынға қолжетімді; сондықтан карточка саны өзгермейтіні түсіндіріледі, таңдау нақты setup өрістеріне беріледі.

КТП санағы: 64 контекст, сынып/пән/тоқсан/атау бойынша 616 тақырып. **Бұл барлық контексте толық дайын сабақ материалы бар дегенді білдірмейді.** КТП 5–11 сыныптарды, ойын банкі 5–7 сыныптарды қамтиды. 1–4 немесе жаңа пән тапсырмалары қосылмады. Бұрынғы конструктордың қолмен 1–11 сынып мәліметін енгізуі сақталды; жаңа сынып банктерін дайындау бөлек жұмыс.

Нақты түзетулер: іздеудің XSS-і; авторизациядан кейін dashboard жаңаруы; жарамсыз ARIA; ойын стилінің sidebar контрастына әсері; 7-сынып қысқа кілтті мысалдары; метадерек жүктелмегендегі адал күй; конструктор стилінің header-ге әсері; қазақша рөл/хабарламалар; нақты мұғалім ескертуін жоқ материал деп белгілемеу. Алғашқы тест шекарасындағы синтаксис/күту мәселелері түзетіліп, тиісті жиынтықтар қайта орындалды. Қайталанған орындалулар қосымша тест деп саналмайды.

## Шектеулер және жариялауға дайындық

Жергілікті QA толық өтті. Код браузерлік қабылдау мен келесі review-ға дайын; нақты өндірістік аккаунттар/құрылғылармен тексеру жариялау алдында қалады. Жариялау жасалған жоқ.

Алғашқы ұзақ орындалуда Қамалдың 390 px / 6-сынып сценарийі сәтсіз белгіленді. Сессия толық есеп жазбай үзілгендіктен, сол белгінің түпкі себебі расталмады. Код өзгертілмей 9 диагностикалық қайталау және кейін толық 93/93 тест өтті; бастапқы журнал сақталған. Өндірістік қабылдауда бұл сценарийдің тұрақтылығын қосымша бақылау қажет.

Нақты өндірістік Firebase аккаунттары/серверлік рөлдерге жазу тесті жасалмады. Нақты телефондар, экрандық оқырмандар, Firefox және WebKit тексерілген жоқ (соңғы екеуі орнатылмаған). Жаңа AI/аналитика функциялары қосылмады. Браузер тесттері басқарылатын Firebase шекарасымен орындалды.

F commit-інен кейін Git қалтасының тазалығы бөлек расталады. Жариялауға дейін нақты аккаунттармен және құрылғылармен қабылдау керек. Бұл тапсырмада push, PR, merge және Pages жариялауы орындалмайды.

QA командалары: TESTING.md. Толық техникалық түзетулер: F-QA.md. Сыртқы артефактілер: `/workspace/audit-math-ai/stage7-iustaz/`.
