# B кезеңі — бренд және дизайн жүйесі

iUSTAZ атауы көрінетін бренд орындарына енгізілді. Техникалық кілттер мен Firebase атаулары ауыстырылған жоқ. Ашық кітап пен i таңбасын біріктіретін түпнұсқа SVG: толық/қысқа, ашық/қараңғы, favicon.

`iustaz-ui.css` бастапқы 7 CSS-ті өшірмей, палитра, Inter, radius, көлеңке, карточка, батырма, өріс, badge, modal, tab, progress, breadcrumb және бос/қате/жүктелу күйлерін береді. Компоненттер iu- префиксімен шектеледі. Inter variable 5.3.0 қарпі @fontsource-variable/inter ресми npm пакетінен; Latin, Cyrillic және Cyrillic Extended бөлімдері жергілікті сақталған, OFL лицензиясы қоса берілген. Жүктелмесе жүйелік sans-serif іске қосылады.

Тексеру: 2/2 қорғау келісімі, 2/2 Chromium бренд/қаріп тексеруі өтті. Барлық бес SVG жүктелді; қазақ әріптеріне Inter FontFaceSet тексеруі өтті. Кеңейтілген контраст және responsive тексеруі F кезеңінде жасалады.
