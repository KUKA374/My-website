# D кезеңі — конструктор және сабақ кітапханасы

Үш панельдің ішкі айналдыруы, фокус және редактор логикасы сақталды; түстер, өрістер, тақырыптар, батырмалар және көрсеткіштер iUSTAZ қабатына бейімделді. Mobile tabs бұрынғыдай жұмыс істейді. Проекторда ортақ chrome жасырылады; print кезінде биіктік/overflow шектеулері алынады.

Кітапханада атау/тақырып іздеуі, 1–11 сынып сүзгісі, нақты сақталған сынып белгісі, бұрынғы өзгертілу уақыты, ашу/көшіру/жою бар. Сүзгілер UID ауысқанда тазаланады. Жаңа скрипт тек оқу үшін repository ашады; барлық жазу Stage 6 батырмаларына беріледі. Ескі сақтау кілттері өзгерген жоқ.

Басты бет сілтемелері конструктордың нақты taskLibrary, savedLessons, lessonTemplate бөлімдеріне фокусты апарады; жаңа сабақ пен сақталған сабақ сілтемелері бұрынғы жоспарды өшірмейді. КТП сілтемесі жаңа құжатқа тек нақты бар тақырыпты таңдайды; сақтау қатесі жаңа сабақ ашуға кедергі болса, бұрынғы құжатқа мазмұн жазылмайды.

Тексеру: бұрынғы 47/47 конструктор тесті және 9/9 жаңа UI тесті өтті (кітапхана, көшірме/жою, UID, сілтемелер, 320/390/768/1024/1440 px). Қорғалған бастапқы JavaScript/CSS хэштері сәйкес. Нақты production Firebase-ге жазу жасалмады.
