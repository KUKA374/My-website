# C кезеңі — навигация және басты бет

Жеті жұмыс бетіне ортақ sidebar/header қосылды; кіру бетіне ықшам бренд көрінісі берілді. Белсенді сілтемелер нақты беттерге немесе конструктор бөлімдеріне бағытталады. Болашақ бөлімдер мен хабарламалар «Жақында» күйінде, жалған деректер жоқ. Мобильді мәзірде focus trap, Escape, inert және бастапқы батырмаға фокусты қайтару бар.

Басты бет қонаққа ашық. Жеке статистика тек Firebase UID мен teacher/admin/super_admin рөлі тексерілгеннен кейін жергілікті репозиторийден оқылады; серверге жазылмайды. Қазіргі деректер: 20 ойын, 64 КТП контекстінен 616 бірегей тақырып (сынып/пән/тоқсан/атау бойынша). Бұл дайын материалдар саны емес. Соңғы сабақтар updatedAt бойынша сұрыпталады. Ескі таңдаулылар мен жеке жинақ идентификаторлары және сақтау кілттері сақталған.

Іздеу хабарламасындағы нақты XSS түзетілді: енгізілген мәтін мен нәтиже мәтіндері HTML-экранирленеді. Бөлім іздеуі нақты сілтемелер береді. Dashboard скрипті shell авторизациясынан кейін жүктелсе де расталған күйді алады.

Тексеру: 9 жаңа Chromium тесті — нақты статистика, қонақ, бөлім іздеуі, XSS және бес өлшемдегі мәзір/overflow. Алғашқы тексерудегі жасырын мобильді sidebar-ды visible ретінде күту қатесі тестте түзетілді; жүктелу кезегіндегі нақты UI ақауы да түзетіліп, жиынтық қайта орындалды. Соңғы нәтиже журналда сақталған.
