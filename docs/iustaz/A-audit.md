## Қауіптер және шешімдер

- Конструктордың UID-кітапханасына сырттан жазу нұсқа қақтығысын тудырады: жаңа UI бұрынғы батырма әрекеттерін ғана шақырады.
- Қосымша auth listener конструктордың тест шекарасын бұзуы мүмкін: оның расталған owner күйін ғана бақылау.
- Ойын ішіндегі қаріп/геометрия өзгерісі нысананың орнын және уақыт тестін бұзады: белсенді ойынның стилін сақтап, каталогты бөлек безендіру.
- Панельдерді қайта құру фокусты жоғалтады: DOM түйіндерін сақтап, жаңа UI қабатын қосу.
- Басып шығару кезінде sidebar/header және экран биіктігінің шектеуі құжатты қиып кетуі мүмкін: print ережелерін браузерде тексеру.
- Жергілікті сақтау серверлік нәтиже емес; басты бетте тек расталған UID дерегі мен нақты каталог статистикасы көрсетіледі.
- КТП тақырыптарының саны дайын материал саны емес. Ойындар банкі тек 5–7-сыныптарға арналған.
- Қонақ басты бетке кіре алады; қорғалған беттердің рөл тексеруі сақталады.
