- Ортақ 12 слайдтық теориялық блок: 1–8/9–12 диапазондары, native fullscreen/fallback, қадамдар және пернетақта.
- ҚМЖ алдын ала көрінісі/PDF, мұғалім енгізетін оқулық параграфы мен жаттығулар, браузерлік revision/UID сақтауы.
