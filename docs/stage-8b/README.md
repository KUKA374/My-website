# Stage 8B — толық сабақ кеңістігі

Негіз: Stage 8A біріктірілген main `2002b7469ca79050781fa55470fda197633ff111`.
Тармақ: `stage-8b-lesson-experience`. Stage 8A жүктеу архитектурасы қайта жасалмады.

## Демоны ашу

```sh
git switch stage-8b-lesson-experience
python -m http.server 8000 --bind 127.0.0.1
```

Браузерде `http://127.0.0.1:8000/lesson-material.html?class=6&subject=math&quarter=1&lesson=1`
ашыңыз. Қолданыстағы Firebase жүйесінде teacher/admin/super_admin рөлімен кіру керек.
Бұл жергілікті көру тәсілі; сайтты немесе Firebase ережелерін жарияламайды. Жеке draft PR
автоматты Pages preview жасамайды. Бұрынғы lesson.html бетіндегі модульдік сабақ сілтемесі сақталған.

## Не өзгерді

- Ақ/ашық күлгін сабақ кеңістігі, анық тақырып, ашылатын КТП оқу мақсаттары және бөлім навигациясы.
  КТП атауы/бөлімі/мақсаты бастапқы каталогтан дәл оқылады. Диагностикалық ID оқушыға көрсетілмейді.
- Бірінші бөлім — видеосабақ. Нақты видео жоқ: «Видеосабақ жақын арада енгізіледі».
  Жарияланған метадерек болса да iframe тек батырманы басқанда жасалады, autoplay қосылмайды.
- Толықтырылған теория: бөлшек мағынасы, тең бөлшектер, қосу/азайту, көбейту, бөлу, аралас сан,
  қысқарту және кері амалмен тексеру. Төрт шығарылған мысал қадаммен ашылады.
- `visuals.js` бірдей typed компоненттерді сабақта және слайдта қолданады: бөлшек жолағы,
  0–1 сан сәулесі, координаталық график және қарапайым бөлшек формуласы. Сыртқы суреттер жүктелмейді;
  SVG/HTML мәтіні контенттен орындалмайды, тек валидацияланған параметрлерден DOM жасалады.
- Дәл 3 жұптық тапсырма, бастапқыда тек біріншісі. Төрт топтың жеке тапсырмалары.
  A деңгейі көрінеді; B/C мұғалім таңдауымен ашылады. Тапсырма жауаптары мен дескрипторлары
  тек орталық «Жауаптарды көрсету» басқаруымен ашылады. Келесі сабақ/UID ауысқанда жауаптар жасырылады.
- 20 ойынның қолданыстағы каталогы қайта пайдаланылады: ойын таңдау, ереже/мақсат, ҚМЖ-ға таңдалған
  атау, каталогты жаңа қойындыда ашу. Ойын, сынып және тақырып каталогтан қолмен таңдалады;
  іске қосу query API ойдан жасалмады, қозғалтқыштар көшірілмеді.

## Презентация

Сол `fractions-review-v1` ортақ 12 слайдтық блок және Stage 8A индексі сақталған.
Бірінші КТП сабағы 1–8, екінші сабақ 9–12 слайдтарын қолданады. Екінші сабақтың толық материалы
қосылмады. Әр слайдта теория/формула/сызба және 2–3 кезекпен ашылатын түсіндіру қадамы бар.
Жұптық/топтық/үй тапсырмалары deck-ке көшірілмейді.

Толық экран нақты Fullscreen API арқылы ашылады. Қолдау жоқ не сұрау қабылданбаса,
«Кеңейтілген көрініс» екені анық жазылады. ←/→, PageUp/PageDown — слайд, Home/End — сабақ
диапазонының шеті, F — толық экран. Esc алдымен native fullscreen-нан, кейін диалогтан шығуы мүмкін.
Диалог жабылғанда, сабақ/UID ауысқанда fullscreen, iframe және жеке ҚМЖ тазаланады.
Қадам батырмасы жасырылғанда фокус слайдқа көшіп, пернетақта басқаруы жалғасады.

Слайд JSON мен KaTeX тек презентация ашылғанда жүктеледі. Кэш/LRU/timeout/abort және ID/range
тексерулері Stage 8A-дан өзгеріссіз қайта пайдаланылады. Өзгерген JS/CSS үшін v=8b белгісі бар.

## ҚМЖ және сақтау

`qmj.js` — тек оқу проекциясы: нақты КТП атауы, бөлім, мақсаттар, 45 минуттық кезеңдер,
мұғалім/оқушы әрекеттері, критерий/дескриптор, ойын және үй тапсырмасы. Preview ішінде тапсырма
жауаптары мен мұғалімнің жеке notes өрісі көрсетілмейді. Браузерден басып шығару/PDF қолданылады.

Мұғалім оқулық параграфы мен жаттығу нөмірін өзі енгізеді. Stage 8A-ның сол
`iustaz-homework-v1:{UID}:{lessonId}` жазбасына optional `textbook: {paragraph, exercise}` қосылды.
Ескі homeworkText/notes/revision жазбалары әлі оқылады, олар жойылмайды; 200 таңбалық book
өрістері қатаң тексеріледі. Save батырмасы, UID/lesson оқшаулауы және revision қақтығысы сақталады.
Бұл autosave немесе серверлік сақтау емес. Notes пен үй тапсырмасы мұғалімнің жеке браузерінде қалады.

`textbook` тек браузерлік optional өріс: оны қолданыстағы Firestore candidate private namespace-іне
жіберетін gateway қосылған жоқ. Болашақ бұлттық көшу үшін бөлек schema/rules review қажет.
`math-ai-lessons-v2:UID` конструктор кітапханасы, Firebase config, Auth рөлдері және production rules
өзгермеді. Серверлік әкімшілік видео жариялау интерфейсі қосылмады.


Stage 8A сақталған 32 тестке Stage 8B-нің 4 модельдік және 12 браузерлік тесті қосылды (48).
Басқа регрессия: 116 ойын, 47 конструктор, 11 каталог/бұрынғы бет, 2 қорғалған келісім.
Барлығы **224/224 өтті, өтпегені 0**. Бір тесттің қайталануы қосымша тест болып саналмайды.
565 ойын тестінің бәрі қайта орындалды деп мәлімденбейді; негізгі suite барлық 20 ойынды
desktop/mobile және 5/6/7 контекстінде басынан аяғына дейін тексереді.

Браузерлік тексерулер Chromium + localhost HTTP, тесттік Firebase Auth шекарасымен орындалады.
Нақты production аккаунттары, Firebase deploy, физикалық принтер және шынайы видео ойнату тексерілмейді.
320/390/768/1440 px, native fullscreen, unsupported fallback, пернетақта/фокус, axe, ҚМЖ және PDF бар.
PDF мәтіні pdftotext арқылы қосымша оқылды; нақты тақырып/мақсат/үй тапсырмасы жоғалмаған.
PDF тестіне Poppler-дің `pdftotext` құралы қажет; әр сөздің bounding box-ы A4 бетінің ішінде тексеріледі.
Stage 8A Firestore ережелері өзгермеді; 7 серверлік emulator тесті бұл жергілікті санға кірмейді.
Осы ортада ресми JAR жүктелуі әлі бұғатталған. Қолданыстағы PR security workflow сақталған;
жаңа PR ашылғанда оның нақты нәтижесін бөлек қарау керек.

Бірінші тест айналымындағы ақаулар: соңғы қадам батырмасы жасырылғанда ArrowRight фокусы жоғалды
(слайдқа фокус көшірумен түзетілді). Native dialog close оқиғасы кезекпен өңделетіндіктен ескі тест
фокусты тым ерте тексерді; енді нақты close/focus күйін күтеді. Бұл күту уақытын көбейту емес.
PDF қосымша тексеруі әдепкі нөлдік жиекте тақырыптың жоғарғы бөлігі қиылатынын көрсетті;
A4 үшін 14/12 mm page margin қосылып, сөз координаталарына регрессиялық тексеру енгізілді.

Артефактілер: `/workspace/audit-math-ai/stage8b/` — viewport/full-page screenshots,
presentation/QMJ көріністері, `qmj-demo.pdf`; тест логтары games/constructor/materials-final ішінде.
