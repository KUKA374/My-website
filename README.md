# Math Teacher Platform

5–11 сынып математика мұғалімдеріне арналған бастапқы сайт.

## Қалай іске қосуға болады?

1. Барлық файлды бір папкада сақтаңыз.
2. `index.html` файлын браузерде ашыңыз.
3. `data.js` файлын өзгертіп, сыныптар мен тақырыптарды өзгертіңіз.
4. Файлдарды GitHub repository-ге жүктеп, GitHub Pages арқылы сайтты жариялауға болады.

## Файлдардың қызметі

- `index.html` — басты бет
- `class.html` — сыныптың ішкі беті
- `admin.html` — бастапқы admin нұсқаулығы
- `data.js` — барлық сынып, тақырып және материал деректері
- `script.js` — сайттың динамикалық жұмысы
- `style.css` — дизайн
